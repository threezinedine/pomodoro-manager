# All slash commands MUST read this file before executing any command. This file contains important guidelines and instructions for the slash commands to follow in order to ensure a consistent and effective workflow

**Keep in mind:**: Load the `templates/project-tree.md` template to structure the project tree and ensure the technical architecture aligns with the defined vision and scope.

**Keep in mind:**: Load the `templates/task-file.md` template to create task files for each major component and feature identified during the brainstorming session. These task files will help track the progress and status of each task throughout the project.

**Important**: Load the `templates/test-commands.md` template to create a test commands file that specifies the necessary tests to be run and passed during the `/execute` command. This is crucial for ensuring that the implementation is correct and meets the requirements, as well as for catching bugs early in the development process.

**Note**: Make sure the `design/test-commands.md` file is created, if not, create an empty one with the content like the empty content which is specified in the `templates/test-commands.md` template.
