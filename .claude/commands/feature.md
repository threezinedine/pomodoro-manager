# Feature Command

**Important**: Read `templates/command-common.md` for general guidelines and instructions that all commands must follow.

With the user input, now only modify the `design/` folder, interact with the user to create the design documents, diagrams, and task list for the project. Do not modify any other files or folders outside of `design/`.

This command be used to work with detailed design on a specific features, create a separate design docuements for each features placed in `design/features/<features>.md`. This is the detail version of `/plan` command, which is more focused on the detailed design of a specific feature, while `/plan` command is more focused on the overall design and architecture of the system.
